# FitNess.ma

Site web moderne de fitness développé avec HTML5, CSS3 pur et responsive design.

## 🚀 Démarrage

```bash
# Lancer le serveur local
python3 -m http.server 8000

# Accéder au site
http://localhost:8000
```

## 📁 Structure

```
gym_site/
├── css/           # Feuilles de style optimisées
├── js/            # Scripts JavaScript (préparé pour futur développement)
├── pages/         # Pages HTML avec sémantique HTML5
├── images/        # Images organisées par catégorie
└── README.md      # Documentation
```

## ✨ Caractéristiques

- **HTML5 sémantique** : Structure accessible et SEO-friendly
- **CSS moderne** : Variables CSS, Flexbox, Grid, animations
- **Responsive design** : Mobile-first avec media queries optimales
- **Accessibilité** : ARIA labels, contraste WCAG, navigation clavier
- **Performance** : Code optimisé, pas de dépendances inutiles

## 🌐 Pages

- **Accueil** : Présentation du centre fitness
- **À propos** : Notre équipe et philosophie
- **Produits** : Suppléments et équipements
- **Contact** : Formulaire de contact
- **Localisation** : Plan d'accès

## 🛠️ Technologies

- HTML5 sémantique
- CSS3 pur (pas de framework)
- Responsive design
- Accessibilité WCAG
- Performance web
